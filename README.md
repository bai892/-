# -
电商用户行为全链路分析项目：数据清洗、RFM价值分层、品类偏好交叉分析、时间维度趋势分析。含数据质量排查与业务策略输出。
一、项目简介
本项目基于 阿里云天池（阿里云）采集的淘宝脱敏数据，使用 Python（pandas, matplotlib, seaborn）进行全链路的数据分析。分析覆盖了数据清洗、描述性统计、用户价值分层（RFM）、品类偏好交叉分析、时间维度趋势分析等。
在分析过程中，我通过业务常识校验，发现了该数据集在多个核心指标上存在高度的不真实性（合成数据/脱敏数据特性），并据此调整了分析框架，最终挖掘出了部分仍有业务参考价值的品类结构洞察。

二、数据源说明
数据来源：阿里云天池淘宝用户行为脱敏数据集
数据体量：5000条行为记录，涉及 798 名用户
核心字段：用户ID、商品ID、品牌、商品类别、行为类型（buy/addbuy）、时间戳、售价、销量

三、分析流程与发现
1. 数据清洗与整体指标初探
过滤了“加购未付款（addbuy）”行为，保留真实成交（buy）记录。
计算得出：
总用户数：798
整体购买转化率：84.18%
复购率：97.86%（异常偏高）
异常排查与业务结论：
真实电商的复购率通常在 20%~30%，97% 复购率完全违背业务常识。结合“人均订单 5.27 单”、“大部分用户都多次购买”的现象，我判断该数据集经过了严重的脱敏和采样偏差处理（偏向高活跃用户）。因此，我认为整体复购率不具备业务参考意义。

2. 品牌销售额分析
各品牌（Apple、Samsung、Huawei、Dell、HP 等）的销售额高度趋同（均在 430万~560万之间），缺乏真实市场的“马太效应”与长尾分布。这种均匀分布进行品牌商业分析没有实际意义，所以放弃品牌维度分析
3. 商品品类销售额分析
按“商品类目ID”聚合后，销售额排序为：
笔记本电脑（1656万）
智能手机（1288万）
相机（739万）
电视（519万）
平板电脑（443万）
智能手表（261万）
耳机（179万）

业务价值：
品类之间的销售额差异，相较于品牌维度更为真实，符合“高客单价商品贡献核心 GMV”的商业逻辑，可以作为后续分析的基础维度。
4. 各品类加购转化率分析
各品类的加购率均在 4.7 ~ 6.5 之间，差异极小。
异常排查与业务结论：
真实电商中，高客单价品类决策成本高，加购转化率应低于低客单价品类。此处差异过小，进一步印证了数据脱敏对行为比例的平滑处理。该指标不作为核心结论。

5. 用户价值分层（RFM 简化版）
使用 pd.qcut 将用户按总消费金额分为低、中、高三层。
可视化呈现：按行归一化后，绘制了“不同价值用户品类消费比例占比”堆叠条形图（见 output 目录），可直观看出高价值用户在笔记本电脑上的消费占比（41.66%）显著高于低价值用户（14.30%）。
计算各层级用户在品类上的消费占比（行归一化）：
价值分层	平板电脑	智能手机	智能手表	电视	相机	笔记本电脑	耳机
低	11.99%	30.91%	10.59%	13.46%	11.07%	14.30%	7.68%
中	10.08%	28.78%	5.89%	11.36%	16.28%	23.16%	4.44%
高	7.26%	22.21%	3.49%	8.87%	14.43%	41.66%	2.09%
业务价值（核心发现）：
高价值用户：偏爱笔记本电脑（41.66%）和相机（14.43%），属于“大件玩家”，追求高客单、深度决策的品类。
低价值用户：偏爱智能手机（30.91%）和耳机（7.68%），属于“小件用户”，偏向低决策成本、轻量级消费。
中价值用户：处于“过渡期”，相机占比（16.28%）显著高于低价值用户，是潜在的消费升级群体。

这一结论高度符合消费心理学中的“决策成本理论“，也是本项目中最具业务参考价值的洞察。

6. 时间维度分析（时段/趋势）
每日销售额/订单量呈周内周期性波动（周末高、工作日低）。
各品类时段销量热力图显示，各品类在 24 小时内的销量分布高度均匀，甚至出现“凌晨 0 点买手机最多”的异常现象。

异常排查与业务结论：
真实用户的消费行为具有明确的作息节律，不可能在全天 24 小时保持均匀分布。结合此前发现的多个异常，可以判断该数据集的时间戳经过了随机脱敏处理，失去了真实的时间维度参考价值。因此，报告仅保留“周内周期性波动”作为辅助参考，不纳入核心结论。

四、核心建议（基于真实且有效的用户分层洞察）
针对高价值用户：
主推笔记本电脑、相机的新品首发、分期免息、以旧换新。
减少低客单价商品的促销打扰，保持品牌高端感。

针对低价值用户：
用智能手机、耳机等轻决策商品做秒杀、满减，提升活跃度。
通过“签到领券”、“小额试用”等方式培养购买习惯。

针对中价值用户：
用相机作为“消费升级”的过渡入口，引导其向高价值用户转化。

数据质量建议：
若需进行真实业务决策，建议补充原始埋点数据或真实业务日志。
在数据分析前，务必增加“业务常识校验”环节，避免被脱敏数据误导。
